LATITUDE 0.9.3 — WINDOWS BETA / LINUX PREVIEW

Windows: run the Setup.exe from GitHub Releases. Open Latitude from its desktop
or Start menu icon. No Node.js, source folder or separate encoder is needed.
For portable use, extract the whole ZIP and keep its files together.

Linux: install the .flatpak through Discover or a Flatpak-capable software center,
then launch Latitude from your application menu. See docs/LINUX.md.

1. Choose your mic in onboarding; Voice 2 and facecam are optional.
2. Add a screen/window and optional camera. Drag sources to arrange the scene.
3. Choose Natural voice or Podcast broadcast, then run Soundcheck.
4. Keep hardware input below clipping. Processed tracks have always-on limiters;
   raw backups preserve the input and cannot repair an overloaded microphone.
5. Record a short test. Check voice, desktop sound, sync and video quality.
6. Separate tracks are on by default. WAV stems work with editors that cannot
   expose multiple audio tracks inside a video file.
7. Enable optional Streaming or Editor in Mods. Recording needs neither.

Already using Latitude? Your saved tone settings remain. Use Voice Studio's
Reapply to adopt the revised preset, then rerun Soundcheck. Input gain, channel,
mute and delay are preserved. Updates are offered once at launch from 0.9.1.
