# Latitude 0.8.0 — the Streaming mod

Windows beta and Linux preview. The first official mod is included, optional and off by default. Open **Mods → Latitude Streaming → Enable**, then **Stream** in the sidebar.

- Mic meters now separate original input from protected output, show headroom and fixed dBFS color zones, and outline a clipping input in red only for its current meter window. A separate history reminder can be reset. Always-on limiter activity is visible for each source and the mix, including with processing bypassed.
- Natural voice starts with rumble filtering, gentle expansion, EQ, compression and de-essing. Protected mic tracks keep the −1.5 dBFS sample ceiling; raw backups preserve the original. Hardware clipping and lossy-codec intersample overs cannot be made impossible by a software limiter.
- Broadcast the Studio scene and processed stereo mix to one RTMP/RTMPS destination. Twitch, YouTube and Custom presets provide starting bitrates. Up to 1080p60 using the Studio size/frame rate.
- Stream without disk recording, or keep a local take with isolated audio tracks. Stop/pause recording and end streaming independently. Pausing a take keeps broadcasting.
- One streaming H.264 encode with hardware preference/software fallback. Bundled FFmpeg copies video and encodes the finished float audio mix to AAC once. No new production dependency, capture graph, DSP stage or always-on service. Simultaneous recording adds its own video encode.
- Status and End stream controls beside the preview and in fullscreen. A global status button opens Stream. Output duration, average encoded frame rate, sent bytes and skipped frames are visible.
- Bounded buffers, startup/write deadlines, orderly shutdown and three reconnect attempts. A local take survives network interruption. Exports wait until streaming ends.
- RTMPS verifies certificates/hostnames. Session-only keys stay out of preferences, packs, diagnostics and application logs. Twitch bandwidth tests are restricted to Twitch ingest addresses.
- Linux Flatpak adds network permission for explicit streaming. Disabled modules stay unloaded and make no connection. Source authors get live-output ownership, transport/panel services, and an implementation example.

The lightweight editor remains planned. Third-party executable installation, account linking, chat, multistream, 4K streaming and SRT/WHIP are not included.

**Verification:** 72 automated tests plus real-browser meter and recording checks; real local receiver/decode tests, TLS rejection, blocked-upload cleanup, AudioWorklet/WebCodecs output, reconnection and recording coexistence. Release gates check bundled Windows/Linux encoders and installed Electron H.264 encoding. See [QA](../qa/streaming-0.8.0.md).

**Platform testing needed:** no authenticated Twitch/YouTube live broadcast or real-speech listening review has been performed. Check a private test before an important show. “Sending” confirms local output activity; the platform dashboard confirms reception/publication. Windows remains unsigned; Linux is a desktop preview, with SteamOS Gaming Mode unsupported.
