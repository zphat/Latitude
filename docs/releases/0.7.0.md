# Latitude 0.7.0 — clearer capture, a calmer studio, and Mods

Windows beta and Linux preview. Download the Windows Setup EXE for normal desktop installation or the Linux Flatpak for an application-menu launcher. The Windows ZIP remains available for portable use.

## Picture and resource use

- Screen capture retains native display pixels until scene cropping and scaling. Small window crops no longer start with an unnecessarily reduced source image.
- Source boundaries align with output pixels. Deadline-based frame pacing compensates for timer jitter and skips missed slots without a burst of catch-up frames.
- Unchanged live previews skip canvas paints. Paused recordings retain their full output dimensions, use preview pacing, and stop drawing when the preview is hidden. Recording keeps its full requested cadence.
- Balanced 1080p30 capture now targets 12 Mbps; High detail targets 20 Mbps. Efficient keeps its previous smaller-file settings. Storage estimates follow the selected quality. Higher detail can mean larger files.
- These changes add no sharpening shader, background service, or runtime dependency. Native-resolution screen sources can still cost more capture bandwidth on large monitors. Actual frame rate depends on the source, GPU, encoder, and scene; 4K60 is a selectable target, not a guarantee on every machine.

## Interface

- Deeper near-black dark themes, more rounded controls, and a refined wireframe globe icon. Signal keeps the electric lime #d1ff4a accent. Linen remains a light alternative.
- Record, pause/resume, a readable recording state, and elapsed time sit beside the preview. Fullscreen preview has its own recording/paused indicator. These controls are checked at smaller window sizes.
- Countdown cancellation no longer clears a newly started countdown.

## Mods foundation

- A dedicated Mods sidebar page manages the installed theme/layout pack, including persistent enable/disable and removal. Existing scenes and recordings survive pack removal.
- Reviewed source modules have a small lazy-loading registry, compatibility checks, declared services, activation/cleanup, and error states. Disabled modules do not load their code.
- Streaming and a lightweight editor are clearly marked as planned. Neither mod is included. This beta does not install arbitrary executable third-party modules; settings packs contain no code.
- The developer guide documents the existing output seam and the further work required for standalone streaming and non-destructive editing. No streaming permissions or editor dependencies were added to the base app.

## Audio and exports

The podcast processing chain, synchronized isolated microphone/desktop tracks, original audio backups, and eight export formats remain available. The capture changes do not replace or flatten your separate audio tracks.

## Preview limits

Windows builds are unsigned. Linux remains an early preview for desktop sessions with distro/device feedback needed; SteamOS Gaming Mode is unsupported. Automated recording and package checks complement, but do not replace, testing on real Windows/Linux capture hardware.

Report problems and share feedback at https://discord.gg/EnPRdDutAn or https://github.com/zphat/Latitude/issues. Include your OS, display resolution, selected quality/frame rate, and whether the issue is visible in the exported video.
