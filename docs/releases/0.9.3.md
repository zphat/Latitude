# Latitude 0.9.3 — voice clarity refinement

A small audio-focused update for clearer, fuller speech while retaining a natural voice.

- Focused de-essing reduces sharp S sounds with less attenuation of lower speech detail. A live reduction readout shows its activity.
- Podcast broadcast removes its small air boost, eases Rich clarity from 35% to 25%, and uses slightly gentler attack/release and quiet-gap reduction. Natural voice has a modest presence adjustment; Soft spoken no longer adds air.
- Voices remain mono and centered. No stereo widening, new lookahead, runtime dependency or extra audio buffer was added. The existing compression and −1.5 dBFS sample limiters remain.
- Saved numeric tone settings are preserved. Select a preset and use **Reapply**, then run **Soundcheck**, to adopt the new defaults. Input gain, channel, mute and sync delay are retained. The revised de-esser runs in enabled chains even with older saved settings.
- Streaming FPS uses actual encoded frames instead of FFmpeg's sometimes unavailable copied-video frame count. Each reconnect resets the measurement.
- Technical details adds an on-demand drawing/recording snapshot without source names or device IDs. Mod help and setup/contributor documentation now reflect the shipped editor and updater.

See [QA evidence](../qa/voice-0.9.3.md) and the [performance/listening guide](../PERFORMANCE.md). Windows remains an unsigned beta; Linux remains a preview. Real microphone listening, long capture sessions on multiple hardware configurations, public streaming platforms and SteamOS Gaming Mode are not certified by automated tests. Sample limiting cannot repair hardware input clipping or guarantee lossy encoded true peaks. Video capture architecture is unchanged in this audio refinement.
