# Latitude 0.9.2 — a new Latitude mark

Latitude now uses its new near-black globe with lime latitude bands across the app header, Windows app/installer/desktop shortcuts, Linux launcher and window icon, and browser icon. The same identity is on the beta homepage and GitHub README.

- The supplied artwork is retained, with dedicated small-size exports and a multi-resolution Windows icon.
- Original artwork and export instructions are included in the open-source repository.
- Static local images only: no new runtime dependency, animation or recording/audio processing change.

Users on 0.9.1 can choose **Update now** at launch or check **Settings → App updates**. Users on 0.9.0 or earlier should install this release manually once to gain update prompts. If an old desktop icon remains cached, relaunch Latitude or recreate its shortcut from the installed app.

Windows remains an unsigned beta and Linux a Flatpak preview. Feedback and updates: https://discord.gg/EnPRdDutAn.
