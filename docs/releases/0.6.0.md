Latitude 0.6.0 adds the first **Linux preview**, alongside the Windows beta.

### Download and open

- **Linux x86-64:** download `Latitude-0.6.0-Linux-x86_64.flatpak`, open it with Discover or a Flatpak-capable software center, and install. Launch Latitude from your application menu or pin it to the panel. You do not need a source folder or Node. [Linux setup and testing guide](https://github.com/zphat/Latitude/blob/v0.6.0/docs/LINUX.md).
- **Windows:** use `Latitude-0.6.0-Windows-x64-Setup.exe`. The installer creates desktop and Start menu shortcuts. The optional ZIP is portable; extract its entire contents. Windows builds remain unsigned.
- `SHA256SUMS.txt` covers the exact downloadable files. GitHub's source archives are for development, not installed applications.

### Linux changes

- Wayland uses your desktop's screen-sharing picker. X11 offers screen/window thumbnails. Separate Screen A/B selection supports document review and side-by-side scenes without duplicate desktop audio.
- Record the default playback output or choose a specific output in Inputs & outputs. Desktop sound connects independently of screen sharing. Microphones, desktop audio, processing and separate tracks use the same audio engine as Windows.
- A small native helper controls the audio-server connection without sending PCM through Electron IPC. It leaves system default devices and volumes unchanged and removes its temporary input on disconnect or exit.
- Clear errors for unavailable audio servers and unsupported old PipeWire versions. Requires PulseAudio or PipeWire 0.3.65+ with its PulseAudio service.
- Flatpak application icon/menu integration, packaged encoder and notices, reviewable Linux diagnostics, and documented permissions.
- Export cancellation now has a bounded fallback when a Linux encoder ignores its initial termination request. Originals and earlier exports remain untouched.

All eight export formats, optional separate embedded audio tracks, WAV editing files, scene tools, voice processing, and themes remain available.

### Scope and known limits

Primary targets are Fedora KDE/GNOME, Ubuntu/Mint with Flatpak, Bazzite, and **SteamOS Desktop Mode**. These are intended targets; real-device capture and long sessions still need testing on those systems. **SteamOS Gaming Mode is not supported by this preview.** Start at 1080p/30 and make a short take before an important session. 4K/60 is available but not a performance guarantee.

Automatic checks cover the shared DSP/storage/export suite, real PulseAudio/PipeWire stereo routing and cleanup, and installation plus desktop-audio processing in the packaged Flatpak. They cannot certify your webcam, monitor, GPU, portal, Bluetooth devices, or desktop hotkey service.

Flatpak needs its shared runtime on first installation. Latitude is not on Flathub yet and has no automatic updater; install newer preview packages from GitHub. The app has no network or full-home-folder permission. Webcam support uses broad device access; audio input/output and Videos-folder access are also granted. Keep recordings in Videos/Latitude if another folder's portal access is not retained.

If you change headphones or speakers, reconnect desktop audio in Inputs & outputs. Per-app audio capture, VST hosting, hardware-encoder selection, and automatic latency correction are not included. See the Linux guide and report issues with your distro, desktop, Wayland/X11, diagnostics, and reproduction steps; no private recording upload is required.
