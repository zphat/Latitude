# Latitude 0.9.0 — optional Editor beta

Latitude Editor turns recordings into episodes, VODs and clips without leaving the app. Enable **Latitude Editor** in **Mods**, then open **Edit**, or choose **Edit** on a saved take. It is included, off by default and uses no paid service.

- Video/audio layers, media import, trims, linked splits, global ripple cuts, drag between layers, insert/append, copy/cut/paste, undo/redo and markers.
- Linked audio separation, gain/pan/mute/solo, waveforms, fades and optional dialogue cleanup. Continuous final audio processing, protected preview and optional podcast loudness matching.
- Draggable framing/crop, images, gradient titles, locally bundled Manrope/DM Serif Display, dissolves/slides/wipes and simple color controls.
- MP4, MKV and WAV export, selected-range clips, optional embedded audio layers and aligned 24-bit WAV stems. Original media remains untouched.
- Local project files, recovery drafts, relinking, compatible preview generation, cancelable rendering and bounded media/undo/export resources. Native byte-range seeking fixes scrub accuracy.
- No new production dependency; disabled editor implementation stays unloaded. Recording and Streaming continue to use their existing capture/audio path.

[Editor guide](https://github.com/zphat/Latitude/blob/main/docs/EDITOR.md) · [QA details](https://github.com/zphat/Latitude/blob/main/docs/qa/editor-0.9.0.md)

This is a first editor beta, not a replacement for a full finishing suite. No automatic captions/filler-word removal, speed ramps, keyframe animation or third-party executable-mod installer. Software export is bounded rather than designed to saturate every CPU core; 4K decoding/rendering still needs appropriate hardware and disk space. Preview effects are approximate. Real-world codecs, GPU performance and SteamOS Desktop Mode need feedback.

Windows installers remain unsigned. Linux is a Flatpak preview. Install from the files below; recordings live outside the app/source folder. Feedback and updates: https://discord.gg/EnPRdDutAn.
