# Latitude 0.9.9 · Editor interaction polish

- **Safer dragging:** while holding a picture or title in the preview, Delete,
  Split, Undo and navigation cannot change the project underneath the drag.
  Release commits the movement; Escape restores the original edit.
- **Less work while scrolling:** the timeline reuses already-rendered rows and
  waveforms for vertical scrolling and small horizontal movements. Moving into
  another region renders the newly visible clips. In the native regression
  fixture, 16 small scrolls now cause zero row replacements instead of 16.
  This measures DOM work, not a hardware CPU/FPS guarantee.
- **Resize without losing your place:** newly exposed timeline regions populate
  when the window widens. Media, selected clip, project settings, playhead and
  Undo history remain intact. Disabling the optional Editor disconnects the
  resize observer and scroll callback.

The offline Creative library from 0.9.8 remains included: transitions, looks,
title styles, fonts and editable local preset packs. No new dependency, framework
or media decoder was added. Recording quality, voice DSP, project and export
formats are unchanged. Existing projects and original source files remain usable.

Windows remains an unsigned beta; Linux an x86-64 Flatpak preview. macOS remains
an unsigned, unnotarized DEVELOPMENT PREVIEW requiring macOS 14.2+, with MANUAL
updates. Automated editor/export/package checks do not replace physical capture,
permissions, long-recording, GPU, signing/notarization or update-installation tests.
