# Latitude 0.9.1 — launch update checks

Latitude now checks for updates at launch and offers **Update now** or **Skip until next launch**. It downloads only after you choose; skipping lasts until the next full launch.

- **Settings → App updates**: manual check, release notes, and a switch for launch checks.
- Windows installed builds open the verified installer and close safely. Linux opens a verified Flatpak in your software center; portable Windows builds open a verified ZIP for manual replacement.
- Setup dialogs and active recording, streaming or exports defer the launch check/prompt. Busy guards prevent installing over live work. Preferences and the latest editor recovery draft save before handoff.
- Cancelable downloads, progress, offline/error states, bounded requests, exact release-asset selection and SHA-256 verification before opening. No new production dependency or recurring background network checks.

**Install 0.9.1 manually once if you are using 0.9.0 or earlier.** Future launches can then notify you of new releases. This release retains the optional Editor and Streaming mods.
