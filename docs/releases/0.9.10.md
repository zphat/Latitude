# Latitude 0.9.10 · Studio reliability and a quieter library

- **Stop recording with confidence.** Stop drains accepted writes and checks the sample count in every isolated track. If the video encoder fails or an audio file is missing, shortened, or cannot be finalized, Takes marks the recording interrupted and shows the reason instead of starting automatic export. A temporary marker-save failure no longer blocks the final save. Other tracks still finalize.
- **Keep the original recording.** Export reads a healthy WAV header without rewriting it; it repairs interrupted headers when needed. A mix-only export does not depend on unrequested mic or desktop files. A requested missing or shortened stem produces an error rather than a misleading multitrack delivery. Odd-length 24-bit mono WAVs now have correct padding.
- **Keep controls in reach.** In compact studio windows, Record/Stop, Pause and Marker stay visible while the mixer and session settings scroll. One damaged session date no longer prevents other takes from appearing. Silence, audio below the loudness gate, and unavailable measurements get distinct labels.
- **Keep the library yours.** Creative library → Options → **Hide premium content** starts enabled. It hides the catalog teaser and filters trusted paid entries in searches, collections and favorites. Local packs and saved edits always work. Searches and hover previews allocate less repeated work. No store, account, payment integration, new decoder or production dependency.

Originals, isolated tracks, capture/export formats, voice processing, and the public pack v1 format remain compatible. Windows is an unsigned beta; Linux is an x86-64 Flatpak preview. Mac is an unsigned, unnotarized development preview for macOS 14.2+, with manual updates.
