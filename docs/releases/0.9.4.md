# Latitude 0.9.4 — a more comfortable editor

The optional Editor fits smaller, non-maximized windows while keeping your current work intact.

- Drag the divider to adjust the preview/timeline balance. Focus it and use Up/Down, Home or End; double-click for an even balance.
- Collapse or reopen Media and Inspector from the workspace buttons. Layout choices are remembered on this device; Reset layout restores defaults for the current window.
- Independently scroll panels and tracks. Long toolbars scroll horizontally; at high display scaling, panels become drawers over the preview and very small effective windows scroll vertically.
- Window/layout changes preserve media, selection, playhead, project settings, unsaved edits and undo history. Existing audio controls and separate-track/stem export remain available.
- No new runtime dependency, framework, media decoder, animation loop or resize polling. Layout listeners are removed when the optional mod is disabled.
- Normalized editor audio explicitly retains stereo layout after resampling, improving bundled-encoder compatibility.

The existing 107-test suite passes. Native Electron checks cover editing, project save, separate-track export, actual divider sizing, interrupted drags, saved preferences and cleanup. Screenshots were inspected at 960×640, 1280×720, larger windows and 125%/150% Chromium zoom. The release pipeline also checks native editor UI on Windows and Linux before publication. [Editor guide](https://github.com/zphat/Latitude/blob/main/docs/EDITOR.md) · [QA evidence](https://github.com/zphat/Latitude/blob/main/docs/qa/editor-workspace.md).

Windows remains an unsigned beta and Linux a Flatpak preview. Zoom tests approximate display scaling; real desktop DPI/GPU, physical devices and long-session capture still need user testing. No measured CPU/RAM improvement is claimed. Recording and voice-processing behavior are unchanged by this editor layout update.

Mac Apple Silicon and Intel **0.9.4 development previews** are available alongside this release, including the same editor improvements. Mac publication is gated on both native encoder test suites, editor/save/separate-track export checks, DMG/ZIP verification and a packaged-app launch. The Mac encoder is built from pinned FFmpeg 6.1.6 and dependency sources without nonfree components. Exact sources, build recipes, license notices and **SHA256SUMS-macOS.txt** accompany the Mac downloads. Existing Windows/Linux binaries and their checksum file are unchanged.

Mac requires **macOS 14.2+** and remains **unsigned and unnotarized**, with manual updates. Real-Mac microphone/camera/screen/system-audio capture, permission prompts and long recordings still need hardware testing. Automated runner checks are not capture certification. A signed Mac beta and automatic Mac update flow remain separate milestones. [Mac setup and test guide](https://github.com/zphat/Latitude/blob/main/docs/MACOS.md).

Windows/Linux: update through **Settings → App updates**, or install the matching download. Mac: save, quit and replace the app in Applications with the matching DMG. Existing projects, preferences and recordings are retained. Feedback and updates: https://discord.gg/EnPRdDutAn.
