# Latitude 0.9.7 — easier everyday editing

- Drag a clip edge and see the first or last retained frame while trimming. A floating readout shows the cut position and remaining length. Picture and linked microphones share the same source limits, including typed inspector trims.
- Move either edge into a cut, marker or the playhead. A cyan guide shows the exact snap target. **Snap · N** is remembered; **Alt** temporarily bypasses it, including while a gesture is held.
- **Escape** cancels a drag and restores the project and playhead. An unfinished timeline gesture also cancels when focus is lost or the editor is closed. Each completed move/trim produces at most one Undo entry.
- **↑/↓** and Previous/Next cut navigate clip boundaries across layers. **Ctrl/Cmd-wheel** zooms around the pointer, **Shift-wheel** scrolls sideways, **+/−** zoom and **F** fits. Holding a drag at an edge scrolls longer timelines.
- Selecting a clip after Undo correctly re-enables Split/Delete/Copy. The ruler stops adding empty scroll space, and zoomed end trims keep a stable timeline width during the gesture, avoiding scroll-induced trim jumps. Save and Export stay visible when a short window needs vertical scrolling.

Timeline pointer events are coalesced to display frames, unchanged placements skip model rebuilding, snap targets are prepared once per gesture, and idle gestures run no animation loop. The editor remains an optional local mod. No production dependency, extra media decoder, recording-format change or voice-processing change was added. Original recordings and existing project settings remain intact.
