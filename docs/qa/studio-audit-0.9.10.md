# Studio reliability audit · 0.9.10

Reproduced four previously untested storage cases on 0.9.9: a failed checkpoint poisoning Stop and new chunks racing closure; loss of a stem going unreported; one incomplete date breaking Takes; and missing RIFF padding on odd 24-bit mono recordings. The four before/after tests in tests/storage.test.cjs fail against the old code and pass on the fix. Another regression exercises an actual FLAC export with a missing separate track: mix-only succeeds with identical original bytes and modification time; requesting the missing track fails explicitly.

- 150 Node tests passed using FFmpeg 7.1.5; includes actual media, pitch/stream order, 24-bit samples, protected vs raw audio, recording recovery, editor, mods, downloadable content service and updater. Seven Mac publication guard tests passed locally.
- An induced MediaRecorder error in the studio now persists a video interruption in Takes and skips automatic export; intact audio stays available.
- Generated devices, real AudioWorklet/MediaRecorder and FFmpeg: the recorded/pause/rename/edit/export path passed; one sample had four audio streams and a 0.030 s difference between raw video end and audio duration. The test now verifies RIFF-declared bits/block alignment instead of assuming raw and processed tracks use identical bytes per sample.
- Browser suites covered scene composition/crop/drag, audio metering, formats, Linux device-routing UI (simulated bridge), storage choices, 1080p capture and a local RTMP listener with reconnect during recording. The native editor, frame-ID scrubbing, gestures, font/preview agreement, save/reopen, isolated-track export, naming, and update UI were exercised. A compact startup capture alone is not a 4K performance certificate.
- The 75-minute accelerated worklet soak produced exactly 215,904,000 recorded frames on each of six streams, including a two-second recording pause with the live feed continuing. Sampled array-buffer growth was 0.98 MiB. This measures the worklet, not wall-clock microphone, video, storage, or transport endurance.
- Visually inspected compact Studio and Creative views; geometry tests at 960×640, 1100×740 and 1280×720 require the main transport to remain reachable while scrolling the mixer and setup. Editor QA also uses 125%/150% zoom. A screen hit-test checks the first Add title button, not merely its presence in the DOM.
- For 140 searches of 1,280 synthetic presets (20 packs), median of five warmed Node runs: 112 ms before, 42 ms after on this host with identical result counts. This times queries only. No new runtime dependency, decoder or network service.

Hardware sign-off is separate: physical Windows, Fedora Plasma/Wayland and macOS capture; permission denial/restoration; actual GPUs; sync on a full 70–90 minute camera/game session; real third-party stream ingest, installation/update and signing. Never equate an offline updater handoff test with executing an installer.
